## 📖 Overview
The Task Manager Dashboard is a lightweight, high-performance productivity tool designed specifically for the Middle Eastern market. It provides a clean interface to organize, prioritize, and track tasks efficiently. Built with simplicity in mind, it works entirely in your browser without the need for complex databases or backend infrastructure.

## ✨ Features
*   **Full RTL Support:** Optimized layout for right-to-left reading flow.
*   **Task CRUD:** Easily add, edit, and delete tasks.
*   **Priority Levels:** Categorize tasks by importance (High, Medium, Low).
*   **Smart Filtering:** Quickly find tasks by their status or priority.
*   **Persistence:** Your data is saved locally in your browser via `localStorage`.
*   **Responsive Design:** Fully functional on desktops, tablets, and mobile devices.

## 🌍 Localization Notes
*   **Language:** The interface is fully localized to Arabic to ensure a native user experience.
*   **Layout:** Implemented using CSS Flexbox/Grid with `dir="rtl"` to ensure proper alignment for Arabic text.
*   **Formatting:** Date and time displays are tailored to common regional expectations.

## 🛠 Tech Stack
*   **Frontend:** Vanilla HTML5, CSS3, and JavaScript (ES6+).
*   **Storage:** Browser `localStorage` API.
*   **Deployment:** Hosted via GitHub Pages.
